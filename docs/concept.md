# Concept

## Overview

이 프로젝트는 웹 브라우저에서 실행되는 가상의 데스크톱 운영체제 프로토타입입니다.

실제 운영체제의 내부 구조를 구현하는 것이 아니라, 운영체제에서 사용자가 경험하는 환경과 상호작용을 하나의 독립적인 작품으로 표현하는 것을 목표로 합니다.

## Goal

사용자가 처음 실행했을 때 일반적인 웹사이트가 아닌, 하나의 운영체제를 사용하고 있다는 느낌을 받을 수 있어야 합니다.

이를 위해 데스크톱, 창, 애플리케이션, 파일 시스템, 설정 등의 요소가 서로 일관된 규칙에 따라 동작하도록 설계합니다.

## Design Philosophy

아직 구체적인 운영체제의 철학은 확정하지 않습니다.

개발 과정에서 여러 운영체제의 UX를 참고하고, 실제 사용 경험을 바탕으로 이 프로젝트만의 인터페이스와 상호작용 방식을 정의합니다.

단순히 기존 운영체제의 외형을 복제하는 것을 목표로 하지 않습니다.

## Scope

프로젝트는 실제 운영체제가 아닌 인터랙티브 프로토타입입니다.

다음 요소를 중심으로 구현합니다.

- Desktop
- Window System
- Application Launcher
- Applications
- Virtual File System
- Settings
- Terminal

실제 하드웨어 제어, 커널, 드라이버, 프로세스 격리 등의 기능은 구현하지 않습니다.

## AI Collaboration

인공지능을 프로젝트의 주요 제작 도구로 사용합니다.

인공지능을 다음과 같은 작업에 활용할 수 있습니다.

- 아이디어 탐색
- UI/UX 시안 탐색
- 코드 생성
- 디버깅
- 그래픽 및 아이콘 제작
- 반복적인 구현 작업

최종적인 작품의 방향, 기능, UX, 디자인 및 구현 결과에 대한 판단은 제작자가 담당합니다.
